# Accomplishments: Week of October 26, 2026

## GitHub PRs & Reviews

- [PR #20009](https://github.com/hashicorp/vault-enterprise/pull/20009) (cont.): Merged the Vault Enterprise fix for plugin-mount recovery: after restoring a missing plugin binary or registration, `plugin reload` can restore writes without restarting Vault.

## JIRA

- [VAULT-51445](https://hashicorp.atlassian.net/browse/VAULT-51445) (cont.): Confirmed [PR #20009](https://github.com/hashicorp/vault-enterprise/pull/20009) merged, closed the issue, and recorded fix versions `1.19.25`, `1.21.14`, and `2.2.2`.

- [VAULT-51708](https://hashicorp.atlassian.net/browse/VAULT-51708) (cont.): Clarified that deregistering an actively mounted plugin can be valid during migration and closed this as a duplicate of [VAULT-51445](https://hashicorp.atlassian.net/browse/VAULT-51445), which tracks the reload-recovery fix.

- [VAULT-51636](https://hashicorp.atlassian.net/browse/VAULT-51636) (cont.): Closed the database rotation investigation after documenting that stale or unreachable database roles can block a mount’s synchronous rotation queue; recommended removing stale roles or upgrading to `1.21.12` or later for the timeout/retry behavior.

- [VAULT-51712](https://hashicorp.atlassian.net/browse/VAULT-51712) (cont.): Closed the reproduced Database Overview credential-display issue after the fix landed, with `2.2.2` recorded as the fix version; the original fix is in [PR #20093](https://github.com/hashicorp/vault-enterprise/pull/20093).

- [VAULT-51723](https://hashicorp.atlassian.net/browse/VAULT-51723): Reproduced and triaged a namespace-creation panic: a silently rejected `agent-registry/` mount leaves `core.agentRegistry` nil, so a later namespace creation panics; documented the fix and logging work in progress.

- [VAULT-51861](https://hashicorp.atlassian.net/browse/VAULT-51861): Created and advanced the task for Vault release-cadence and maintenance guidance, linked to [PR #3746](https://github.com/hashicorp/web-unified-docs/pull/3746), and moved the docs to review.

## Summary

- Work focused on Vault’s external-plugin lifecycle and mount recovery, database secrets-engine rotation and credential workflows, and diagnosing a namespace-creation failure involving the agent registry. I also advanced Vault release and maintenance documentation and added safeguards for preparing and validating customer-specific Vault builds.
