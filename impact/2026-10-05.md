# Accomplishments: Week of October 5, 2026

## GitHub PRs & Reviews

- [Oracle plugin PR #34](https://github.com/hashicorp/vault-plugin-database-oracle-enterprise/pull/34): Opened a PR adding opt-in `{{current_password}}` support for Oracle root-rotation statements using `REPLACE`, while keeping the default rotation SQL unchanged.
- [Vault docs PR #3597](https://github.com/hashicorp/web-unified-docs/pull/3597): Reviewed the token-create documentation and suggested clarifications for `-ttl`, `-period`, and `-explicit-max-ttl`; the PR merged October 7.

## JIRA

- [VAULT-51145](https://hashicorp.atlassian.net/browse/VAULT-51145): Triaged Oracle root-credential rotation failures with restricted accounts, reproduced the behavior, and validated the proposed `REPLACE` statement in [Oracle plugin PR #34](https://github.com/hashicorp/vault-plugin-database-oracle-enterprise/pull/34).
- [VAULT-48303](https://hashicorp.atlassian.net/browse/VAULT-48303): Followed up after a customer reported LDAP static-role rotation behavior resurfacing in 2.1.1, routing questions about rotation cadence and metadata to the customer-engineering thread.
- [VAULT-50985](https://hashicorp.atlassian.net/browse/VAULT-50985): Added a local reproduction showing Terraform's `jsonencode({})` becomes a literal `{}` credentials path for GCP managed keys, while Vault signs successfully when per-key credentials are unset.
- [VAULT-51159](https://hashicorp.atlassian.net/browse/VAULT-51159): Reproduced the Vault Agent Injector invalid-certificate warning flood and added a measured two-minute count of about four million log lines.
- [VAULT-51194](https://hashicorp.atlassian.net/browse/VAULT-51194): Documented and triaged an LDAP static-role creation panic when password-policy lookup fails before a WAL exists, capturing the nil-WAL rollback path and observed `EOF`/panic.
- [VAULT-51195](https://hashicorp.atlassian.net/browse/VAULT-51195): Filed a repro-verified LDAP static-role bug showing manual rotation updates the reported next-rotation time while the original scheduled job still runs; recorded high severity and linked [VAULT-48588](https://hashicorp.atlassian.net/browse/VAULT-48588).
- [VAULT-51328](https://hashicorp.atlassian.net/browse/VAULT-51328): Added customer evidence and code references for unsupported self-managed password rotation with LDAP RACF schemas, marking the report as not independently reproduced; clarified in [VAULT-49977](https://hashicorp.atlassian.net/browse/VAULT-49977) that this differs from the older RACF schema-validation issue.
- [VAULT-51260](https://hashicorp.atlassian.net/browse/VAULT-51260): Reproduced an LDAP library UI issue where cross-namespace policy capabilities work through the CLI but the UI omits check-in/check-out actions, and attached evidence for triage.
- [VAULT-46707](https://hashicorp.atlassian.net/browse/VAULT-46707): Updated the fix version to 2.1.0 for the Kubernetes auth UI issue where JWT-token changes were not saved.
- [VAULT-48835](https://hashicorp.atlassian.net/browse/VAULT-48835), [VAULT-48837](https://hashicorp.atlassian.net/browse/VAULT-48837), and [VAULT-48838](https://hashicorp.atlassian.net/browse/VAULT-48838): Recorded progress on drafting and validating CE workflow skills for bug triage, escalations, coding, and PR review, with mature work intended for consolidation into `vault-tools`.
