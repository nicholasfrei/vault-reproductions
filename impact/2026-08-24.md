# Accomplishments: Week of August 24, 2026

## Accomplishments

### Vault Enterprise PR's

- [PR #18038](https://github.com/hashicorp/vault-enterprise/pull/18038) (cont.): Fix upgraded Vault UI default-auth configuration behavior.

### JIRA

- [VAULT-48303](https://hashicorp.atlassian.net/browse/VAULT-48303): LDAP static-role manual rotation did not reset credential TTL and next rotation time as expected. Confirmed the plugin fix and closed the issue.

- [VAULT-49510](https://hashicorp.atlassian.net/browse/VAULT-49510) (cont.): Default-auth configuration broke after upgrades because of a root-namespace storage and lookup inconsistency. Documented the affected versions and delete-and-recreate workaround, then closed the issue.

- [VAULT-49618](https://hashicorp.atlassian.net/browse/VAULT-49618): Vault UI namespace-login slash entry caused flickering on Vault `2.0.3+ent`. Picked up the issue and began the customer-impact investigation.

- [VAULT-49661](https://hashicorp.atlassian.net/browse/VAULT-49661): `vault recover -snapshot-id` panicked without a path argument. Created, triaged, reproduced, and tested the fix against a custom binary.

- [VAULT-49729](https://hashicorp.atlassian.net/browse/VAULT-49729): Control-group audit logging omitted the `response` entry and wrapped-token accessor for blocked requests. Verified the behavior on Vault `1.21.3` and triaged the issue.

- [VAULT-48836](https://hashicorp.atlassian.net/browse/VAULT-48836): Added Vault AI-tools course, readings, and secure support-agent skill links, then completed the ELH teaching-course task.
