# Accomplishments: Week of September 7, 2026

### Vault Enterprise PR's

- [PR #18513](https://github.com/hashicorp/vault-enterprise/pull/18513): Deduplicate global reload cleanup scheduling, delete expired request records, and avoid full storage-tree scans. The PR was merged on September 14.

### JIRA

- [VAULT-50116](https://hashicorp.atlassian.net/browse/VAULT-50116) (cont.): Root-namespace `vault plugin reload -mounts` returned a 404 instead of reloading the requested mount. Documented the defect and confirmed fixes targeted to Vault `1.20.16`, `1.21.11`, `2.1.1`, and `2.2.0`.

- [VAULT-49977](https://hashicorp.atlassian.net/browse/VAULT-49977): LDAP secrets engine rejected valid `racf` schema configuration on Vault `1.19.16` through `1.19.20`. Triaged and documented the regression.

- [VAULT-50316](https://hashicorp.atlassian.net/browse/VAULT-50316): Global plugin reload cleanup could cause OOM and quorum loss at scale. Created and investigated the issue, tracking deduplicated scheduling and scoped storage scans as remediation work for `VAULT-50116`.
