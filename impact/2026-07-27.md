# Accomplishments: Week of July 27, 2026

### Vault Enterprise PR's

- [PR #16870](https://github.com/hashicorp/vault-enterprise/pull/16870): Fix StatsD/Statsite sink errors by updating `go-metrics` to v0.6.1, correcting formatting and adapters, and expanding telemetry test coverage.

### JIRA

- [VAULT-48027](https://hashicorp.atlassian.net/browse/VAULT-48027) (cont.): Terraform provider partial database-role payloads omitted unchanged fields and risked role corruption. Documented the behavior across Vault versions and moved the issue to Blocked pending customer information.

- [VAULT-43281](https://hashicorp.atlassian.net/browse/VAULT-43281): Terraform provider AWS-auth regression caused `PUT /v1/auth/aws/login` failures on older Vault versions. Reproduced and closed the issue, identified [Vault PR #10961](https://github.com/hashicorp/vault/pull/10961), and documented upgrade or provider-pinning workarounds.

### Vault Reproductions Improvements

- [LDAP dynamic-role uppercase-name reproduction](../secrets/ldap/ldap-dynamic-role-uppercase-bug-repro.md): Documented the create/list/read/delete lifecycle failure and confirmed the orphaned raw-storage entry.

- [Terraform Provider AWS-auth `PUT` regression runbook](../auth/aws/terraform-provider-aws-auth-put-runbook.md): Connected provider 5.7.0 AWS SDK Go v2 presigning to older Vault versions and documented reproduction and workarounds for [VAULT-43281](https://hashicorp.atlassian.net/browse/VAULT-43281).

- [Snowflake database-role partial-payload reproduction](../secrets/database/snowflake-db/vault-db-role-update-partial-payload-repro.md) (cont.): Corrected the reproduction reference while investigating [VAULT-48027](https://hashicorp.atlassian.net/browse/VAULT-48027).

- [AWS/Kubernetes development setup](../setup/aws/README.md): Added an AWS Terraform dev-server configuration and reorganized Kubernetes scripts for repeatable Vault Enterprise environments.

### Summary 

- This week touched Vault telemetry sinks and metrics formatting, AWS authentication request-method compatibility across Vault and the Terraform provider, LDAP dynamic-role storage and case handling, and database secrets-engine role updates. The reproductions and runbooks also improved the AWS/Kubernetes development environment used to validate Vault Enterprise and provider behavior.
