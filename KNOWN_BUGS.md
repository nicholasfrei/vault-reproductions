# Known Bugs & Regressions

This is not an exhaustive list. The version columns are stale. They reflect whatever was recorded when each scenario was written, and they are not kept in lockstep with every Vault release. A missing "Fixed versions" value does not mean the bug is still open. It only means a fix version was not recorded here yet. Those rows sit at the bottom.

For current upgrade impact, use HashiCorp's lists instead:

- [Important changes](https://developer.hashicorp.com/vault/docs/updates/important-changes)
- [Release notes](https://developer.hashicorp.com/vault/docs/updates/release-notes)
- [Vault CHANGELOG](https://github.com/hashicorp/vault/blob/main/CHANGELOG.md)

Rows with a recorded Vault fix are sorted by that version, newest first (`2.1.x`, then `2.0.x`, etc.). KBs, runbooks, and guides stay in the [topic-folder indexes](README.md#start-here).
